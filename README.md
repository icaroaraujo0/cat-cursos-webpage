📚 Catálogo de Cursos

Um projeto simples de página web para exibição de um Catálogo de Cursos, desenvolvido para praticar conceitos fundamentais de desenvolvimento front-end como estruturação semântica HTML5 e CSS3

🖥️ Demonstração da Interface

O projeto consiste em um cabeçalho fixo com navegação e uma área principal responsiva que exibe os cards dos cursos oferecidos (Sistemas de Informação, Administração, Arquitetura e Urbanismo, etc.).

📌 Aprendizados e Conceitos Aplicados

CSS Reset: Uso de box-sizing: border-box e zeramento de margens/paddings padrão.

Flexbox: Utilizado para alinhar o título e a barra de navegação no topo da página.

CSS Grid: Construção do grid de catálogo que se adapta ao número de cards apresentados.

Componentização Visual: Criação de cards com sombra, espaçamentos internos e botões de interação.

✍️ Desenvolvido para fins de estudo e prática de Front-end.
